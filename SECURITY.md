# Polityka bezpieczeństwa

## Zgłaszanie luk

Jeśli znalazłeś lukę bezpieczeństwa, nie publikuj jej w zwykłym issue ani w pull requeście. Najlepiej użyj prywatnego formularza **Private vulnerability reporting** na karcie `Security` repozytorium albo utwórz prywatną poradę bezpieczeństwa.

Jeżeli prywatne zgłoszenie nie jest dostępne, skontaktuj się z właścicielem repozytorium przez GitHub i nie umieszczaj w publicznej wiadomości danych pozwalających wykorzystać lukę.

W zgłoszeniu podaj:

- opis problemu i potencjalnych skutków;
- wersję aplikacji, system i urządzenie, którego dotyczy problem;
- dokładne kroki odtworzenia;
- minimalny bezpieczny przykład lub nagranie, jeśli jest potrzebne;
- informację, czy problem dotyczy Windows, Androida, czy obu platform.

Nie przesyłaj haseł, kluczy podpisujących, tokenów, danych osobowych ani pełnych danych użytkowników. Jeśli sekret został ujawniony, unieważnij go lub zmień przed zgłoszeniem.

## Obsługiwane wersje

Wsparcie bezpieczeństwa dotyczy przede wszystkim najnowszego wydania dostępnego w [GitHub Releases](https://github.com/Landi545/Cinema-Movie-Finder/releases/latest) oraz bieżącej gałęzi `main`. Starsze wydania mogą mieć nieaktualne zależności, mniej zabezpieczeń i nie muszą działać poprawnie na każdym urządzeniu.

## Co dzieje się po zgłoszeniu

1. Zgłoszenie zostanie potwierdzone po wstępnej weryfikacji.
2. Problem zostanie oceniony pod kątem wpływu i możliwości wykorzystania.
3. Poprawka będzie przygotowana i przetestowana przed publikacją.
4. Po usunięciu luki zostaną opublikowane informacje o poprawce, jeśli nie zwiększy to ryzyka dla użytkowników.

Prosimy o odpowiedzialne ujawnianie informacji i niewykorzystywanie znalezionej luki przeciwko innym osobom. Testy powinny dotyczyć wyłącznie własnych danych i środowisk.
